# 모두를 위한 학교 콘서트장 만들기 — 신규 SQLite + 교사 운영자

## 요구 환경

- Python 3.10 이상
- `pip install -r requirements.txt`
- 실행: `streamlit run run.py`
- 학생은 4~15자리 숫자 학번으로 회원가입하고, 비밀번호 8자 이상을 사용합니다.

## 새 데이터베이스

- 기본 DB: **`concert_school_new.db`** (프로그램 시작 시 자동 생성)
- 과거 `myproject.db`는 사용하거나 마이그레이션하지 않습니다.
- 기존 DB와 혼합하지 않으려면 배포 환경의 `CONCERT_DB_PATH`가 이전 DB를 가리키지 않는지 확인하세요.
- 학생·교사 계정, 모둠, 초대, 활동 기록, 로그인 토큰이 새 DB에 저장됩니다.
- `.gitignore`에 DB 파일이 포함되어 있으므로 DB와 비밀번호를 GitHub에 업로드하지 마세요.

## 교사용 운영자 계정 (새 데이터베이스 자동 생성)

프로그램 첫 실행 시 신규 SQLite DB에 아래 계정이 **자동으로 등록**됩니다.

- 이름: **교사용 계정**
- 아이디: **20262026**
- 초기 비밀번호: **00000000**
- 역할: `teacher` (전체 모둠 열람/편집, 모둠원 이동·추방, 모둠장 변경 가능)

일반 학생 신규등록 창에서는 교사 권한을 만들 수 없습니다.
비밀번호는 SQLite에 **솔트된 PBKDF2 해시**만 저장됩니다.

**보안 필수 안내:** 위 초기 비밀번호는 공개되고 추측하기 쉬우므로, 실제 학생들이 접근하는 공개 URL에 배포하기 전에 Streamlit Cloud > Settings > Secrets에서 **강력한 비밀번호로 바꾸고 새로운 DB에 적용**하세요. 설정 예시:

```toml
CONCERT_TEACHER_ID = "20262026"
CONCERT_TEACHER_NAME = "교사용 계정"
CONCERT_TEACHER_PASSWORD = "새로운_고유_강력_비밀번호_12자이상"
```

계정은 **최초 생성 시**의 비밀번호로 등록되며, 이미 생성된 계정의 비밀번호는 Secrets 값 변경만으로 변경되지 않습니다. 운영 중인 DB에서 비밀번호를 바꾸려면 별도 관리자 비밀번호 변경 작업이 필요합니다. 초기 DB를 새로 만드는 경우에는 새 Secrets 값이 반영됩니다.
실제 `.streamlit/secrets.toml` 및 DB 파일을 GitHub에 업로드하지 마세요.

## 로그인 화면 위치 수정

새로고침 토큰을 확인하는 숨김 컴포넌트에 `100dvh`가 잘못 적용되던 CSS를 수정하여, 로그인 폼이 브라우저 상단에 표시되도록 했습니다. 학습 화면에서의 전체 높이와 단일 스크롤 구성은 그대로 유지합니다.

## 모둠 기능

- 학생 한 명은 활성 모둠 하나만 참여할 수 있습니다. 초대는 학생이 수락해야 가입됩니다.
- 모둠장은 본인 이외의 모둠원을 **추방**할 수 있습니다(초대된 회원도 취소 가능).
- 교사는 **모든 모둠**을 선택하여 공동 기록 수정, 학생 배정 및 타 모둠에서 이동, 추방, 모둠장 변경, 모둠명 변경이 가능합니다.
- 다른 모둠의 **모둠장**을 직접 이동시킬 수는 없습니다. 우선 교사 계정에서 그 모둠의 모둠장을 다른 학생으로 변경해야 합니다.
- 모둠 소개/활동 주제 입력란은 없습니다.
- 공동 기록은 약 3초마다 변경을 동기화하되 전체 화면을 다시 만들지 않도록 유지합니다. 같은 항목을 동시에 수정하면 최종 저장값이 우선할 수 있습니다.

## 로그인 유지

브라우저 내 `localStorage`에 무작위 토큰을 저장하고, 서버 DB에는 SHA-256 해시만 저장합니다.
**로그아웃하면 토큰을 폐기**하므로 재로그인이 필요합니다.
브라우저 저장소·쿠키/사이트 데이터 삭제, 서버 DB 초기화/손실, 다른 브라우저/도메인 접속 등에는 다시 로그인해야 합니다.
개인정보가 있는 공용 PC에서는 반드시 로그아웃하고, 장기간 유지되는 로그인 토큰의 도용 위험에 주의하세요.

## 배포 시 SQLite 보존 — 중요

Streamlit Community Cloud는 로컬 SQLite 파일의 영구 보존을 보장하지 않습니다.
**재부팅·재배포 후에도** 학생과 교사 계정 및 공동 기록을 보존하려면 영구 디스크를 제공하는 서버에서 실행하거나 외부 영구 DB로 변경해야 합니다.
예: 영구 디스크가 `/var/data`에 마운트된 서버는 `CONCERT_DB_PATH=/var/data/concert_school_new.db`로 지정합니다.
SQLite 파일은 하나의 서버 인스턴스에서 사용해야 합니다. 여러 인스턴스가 DB 파일을 공유하는 방식은 지원하지 않습니다.


## 이번 수정: 로그인 화면과 교사 메뉴 제한
- 로그인 복원용 숨김 컴포넌트를 로그인/회원가입 폼 아래로 옮겼습니다. 로그인 창은 Streamlit 본문 맨 위에서 표시됩니다.
- 교사 계정은 현재 모둠을 선택하지 않은 경우에도 환경 1차시/2차시, 기술·가정, 계산 원리 탭을 자유롭게 열 수 있습니다.
- 교사가 수업 입력값을 공동 저장하려면 모둠 협업에서 편집할 모둠을 선택해야 합니다.
- 기존 교사 초기 계정(20262026 / 00000000)은 유지됩니다. 실제 공개 배포 시 초기 비밀번호를 변경하세요.


## 교사용 회원 삭제
교사 로그인 → 모둠 협업 → 교사용 · 학생 회원 관리 → 학생 선택 → 해당 학번 입력 → 학생 계정 영구 삭제.
삭제 시 회원의 로그인 세션, 모둠 소속/초대, 개인 기록은 함께 삭제되고, 모둠별 공동 활동 기록은 유지됩니다.
삭제 대상이 모둠장이면 우선 교사 권한으로 모둠장을 다른 활성 모둠원으로 변경해야 합니다.
삭제는 되돌릴 수 없으므로 DB 백업을 권장합니다.


## 교사용 모둠 영구 삭제 (신규)

교사용 계정 로그인 → 모둠 협업 → 모둠 선택 → **교사용 · 모둠 영구 삭제**에서 모둠 이름을 다시 입력하고 최종 확인하세요.

모둠 삭제 시 학생 계정(users)은 유지됩니다. 해당 모둠의 group_members(소속·초대) 및 group_records(모둠 공동 활동 기록)가 외래키 연쇄 삭제로 제거됩니다. **되돌릴 수 없으므로 먼저 DB 백업을 다운로드하세요.**

## 운영 중인 DB 다운로드 (교사 전용)

교사로 로그인하면 **운영 중인 SQLite DB 다운로드 (교사용)** 버튼이 표시됩니다. SQLite의 안전한 온라인 백업 API를 이용해 생성한 복사본을 다운로드합니다. DB Browser for SQLite에서 열 수 있습니다. 학생 개인정보가 포함되어 있으니 외부 공유를 금지하세요.

## 별도 제공되는 DB 파일

ZIP 안과 별도 링크로 제공되는 `concert_school_new.db`는 **신규 초기화된 예시 DB**입니다. 이 파일에는 Streamlit Cloud에서 실제 가입한 학생의 회원 정보가 들어 있지 않습니다. 실제 학생 기록은 위의 교사 전용 다운로드로 받아야 합니다.

주의: Streamlit Community Cloud의 임시 로컬 디스크는 앱 재시작 시 보존되지 않을 수 있습니다. 운영 기록의 장기 보존에는 영구 저장소가 필요합니다.
